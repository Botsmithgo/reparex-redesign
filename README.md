# Reparex — Website Redesign (Concept)

A modern, conversion-focused homepage redesign concept for **Reparex** ("For Grey Hair") — a gradual, no-dye hair-color restoration treatment by BOOS LABS.

### 🔗 Live demo
**https://botsmithgo.github.io/reparex-redesign/**

---

### What this is
A high-fidelity, fully responsive homepage prototype built to fix the trust and conversion problems of the existing site (dated, ad-infested, zero social proof) and to speak directly to the core buyer: a skeptical, midlife audience that's **not ready to go gray** — designed especially for the fast-growing male segment.

### Highlights
- **Confident, credible direction** — dark, premium hero led by a real midlife customer; proof and guarantee pushed up front.
- **Warm botanical-premium system** — deep forest green + cream + terracotta, Fraunces + Inter type.
- Full conversion stack: hero with Women / Men / Beard paths, "how it works" + results timeline, before/after slider, "why Reparex" comparison, product trio, testimonials, heritage, FAQ, guarantee.
- Responsive (375 / 768 / 1024 / 1440px), accessible, light/fast — no third-party ads.

### Note on content
Imagery and reviews are **representative placeholders** clearly marked in-page — to be replaced with real product photography, customer before/afters, and verified reviews.

### Tech
Static `index.html` — Tailwind (CDN), Google Fonts (Fraunces + Inter), Lucide icons. No build step; just open the file or visit the live link.
